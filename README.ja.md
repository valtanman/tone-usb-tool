# TONE USB ツール

[English → README.md](README.md)

Linux(KDE / GNOME)用の、**ISOをUSBに書き込む**・**USBを強制的に真っ白にする**ためのGUIツールです。
TONE OS の一部ですが、Ubuntu 系の Linux なら単体で使えます。表示言語は**日本語と英語**(自動判定)で、言語ファイルを足せば他の言語も使えます。

> ## ⚠ 必ずお読みください
> このツールは、選んだ USB のデータを**完全に消します。元には戻せません。**
> 使用中(マウント中)でも強制的に外して消します。対象はよく確かめてから実行してください。
> 無保証です(MIT ライセンス)。大事なデータは、先にバックアップしてください。

## できること

| 機能 | 内容 |
|---|---|
| **全部入り** | 完全消去 → ISO書き込み → SHA-256検証 → 安全な取り外し(電源オフ)を、確認1回で連続実行 |
| ISOを書き込む | 書き込み後に ISO と読み戻しを SHA-256 で照合 |
| USBを真っ白にする(強制) | 使用中でも外して、署名・パーティション表・先頭と末尾を消去。「完全消去」は全域 |
| ISOの事前照合 | ISOの隣に `.sha256` か `SHA256SUMS` があれば、書く前に照合 |

## 安全のための仕組み

- **いま動いているシステムのディスク**(起動ディスク・ライブ媒体)と、**ISOが入っているディスク**は、候補にも出さず、強制でも受け付けません。
- 選んだ後に**容量・シリアルが変わった**(抜き差しで入れ替わった)ら、拒否します。
- 書き込み先は**本物のブロックデバイスだけ**です。デバイスが一瞬消えても、普通のファイルを作ったり書いたりしません(戻るまで待ち、消えたままなら何も書かずに中止)。
- 内蔵ディスク(USBではないもの)は、USBが見つからないときだけ選べ、**デバイス名の全体を入力**して初めて実行します。
- 結果は必ずダイアログで表示し、記録を `~/.cache/tone-os/usb-last.log` に残します。

## インスコ

```bash
sudo bash install-tone-usb-tool.sh
```

メニューの「TONE USB ツール」から起動できます。ISOファイルを右クリックして開くこともできます。

アンインスコ:

```bash
sudo bash install-tone-usb-tool.sh --uninstall
```

必要なもの: `kdialog` または `zenity`、`pkexec`(polkit)、`util-linux`、`gdisk`(インスコ時に自動で導入を試みます)。

## 言語

表示言語は環境の言語設定(`LANG`)に従います。日本語(`ja`)と英語(`en`)を内蔵し、それ以外は英語になります。

言語を足すには(例: アラビア語)、`lang/en.lang` を `ar.lang` にコピーし、各行 `key=value` の右側を翻訳して、次のどちらかに置きます。

- `~/.config/tone-usb/lang/`(自分だけ)
- `/usr/local/share/tone-usb/lang/`(全ユーザー)

決まり: `\n` は改行、`%1 %2 …` は値の差し込みです。足りないキーは英語で補います。言語ファイルは**データとして読むだけで実行されない**ので、言語ファイルからコマンドを動かすことはできません。管理者権限で動く `usb-root` は言語ファイルを一切読まず、メッセージのコードだけを出します。

言語を固定するには: `~/.config/tone-usb/language` に言語コードを書きます(例: `echo ja > ~/.config/tone-usb/language`)。一度だけ試すなら `TONE_LANG=ar tone-usb-flash` です。優先順位は、`TONE_LANG` → このファイル → 環境の言語 です。

## ファイル構成

- `install-tone-usb-tool.sh` … 自己展開インストーラ(`src/`・`lang/` と同じ内容)
- `src/tone-usb-flash` … 画面(kdialog / zenity)
- `src/usb-root` … 管理者権限で動く本体(`pkexec` 経由)
- `lang/*.lang` … 言語ファイル
- `SHA256SUMS` … 配布ファイルの照合用(`sha256sum -c SHA256SUMS`)

## うまくいかないとき

- 結果の記録: `cat ~/.cache/tone-os/usb-last.log`
- `/dev/sdX` が普通のファイルになっている(古い版の失敗の残り): `sudo rm -f /dev/sdX /dev/sdX[0-9]*` のあと USB を挿し直す
- 「読み取り専用のまま」: USB本体の書き込み禁止スイッチを確認し、別の口(USB2.0がおすすめ)に挿し直す
